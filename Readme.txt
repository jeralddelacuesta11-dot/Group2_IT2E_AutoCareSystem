# 4Ds Auto Care System

## Description

The 4Ds Auto Care System is a Java-based application designed to manage basic car and motorcycle repair and maintenance services.

The system allows users to manage vehicle information, perform inspections, create service orders, track maintenance, and record payments.

## Requirements

* Java JDK installed
* IntelliJ IDEA, Eclipse, NetBeans, or any Java IDE

## How to Run

1. Download or clone the project.
2. Open the project using your preferred Java IDE.
3. Locate `Main.java`.
4. Run `Main.java`.
5. Follow the instructions shown in the console.
6. Choose an option from the main menu to use the system.

## Main Features

* Vehicle Registration
* Digital Vehicle Passport
* Vehicle Inspection
* Service Order
* Maintenance Tracking
* Billing and Payment
* Service History

## Technologies Used

* Java
* Scanner for user input
* Variables and data types
* Operators
* If-else statements
* Switch statements
* Ternary expressions
