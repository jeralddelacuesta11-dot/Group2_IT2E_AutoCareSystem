# 4Ds Auto Care System

## Description
The 4Ds Auto Care System is a Java-based application for managing basic car and motorcycle repair and maintenance services.

## Requirements
- Java JDK installed
- Java IDE (IntelliJ IDEA, Eclipse, NetBeans, etc.)

## How to Run
1. Open the project in your Java IDE.
2. Locate `Main.java`.
3. Run `Main.java`.
4. Follow the instructions displayed in the console.
5. Choose an option from the main menu.

## Main Features
- Vehicle Registration
- Digital Vehicle Passport
- Vehicle Inspection
- Service Orders
- Maintenance Tracking
- Billing and Payment
- Service History
